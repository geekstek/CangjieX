倉頡星 V2.0.4 加入可持續排查「輸入法變灰、無法切換」的本機診斷與安全修復。

### 診斷記錄

- 保存啟動、輸入法伺服器建立、啟用／停用、輸入源狀態、喚醒／登入階段、引擎錯誤代碼與慢處理事件。
- 每分鐘記錄狀態並檢查主執行緒是否逾時；每五分鐘保存經過濾的系統端點訊號，方便還原故障時間線。
- 匯出時附上磁碟與執行中版本、建置識別、PID、來源狀態，以及 macOS 異常報告的時間與類型摘要。
- 不包含按鍵、字根、輸入文字、候選、詞頻、剪貼簿、視窗標題或原始系統／當機報告；不會自動上傳。
- 事件檔最多四段，每段 256 KB；匯出報告保留最近三份。目錄與檔案僅限目前使用者存取。

### 診斷與修復

在「關於倉頡星」按 **診斷與修復…**，可儲存報告或執行安全修復。輸入法變灰、無法開啟選單時，可直接執行：

```sh
"$HOME/Library/Input Methods/CangjieXPreview.app/Contents/MacOS/CangjieXMaintenance" diagnostics-dialog
```

修復前先完成文字、切換到 ABC、離開密碼欄位，並結束「系統設定」。工具會先保存現場，優先刷新註冊與選單；仍失敗時重新核對安全條件，必要時只重啟一次，再保存結果。設定及詞頻保留。系統選用成功後仍須實際試打確認。

喚醒或登入階段切回後，只有來源仍啟用、已選 ABC、沒有待處理組字、未開系統設定且非安全輸入時，才會刷新註冊與選單。十分鐘內最多一次，十五分鐘後過期；不會自動切換、啟用來源或重啟程序。這是對已觀察到的同步故障加上恢復措施，尚未證明所有長期復發的根因。

### 安裝

推薦下載 **CangjieX-2.0.4-universal.dmg**，開啟內部的 **倉頡星安裝器**。完成組字、切 ABC 並結束系統設定後，按「安裝並啟用」，安裝期間保持 ABC。看到「已完成安裝並啟用新版」才算完成；若顯示尚未完成，請依提示保存工作後重新登入。

手動 **CangjieX-2.0.4-universal.pkg** 安裝後須登出並重新登入。支援 Apple Silicon 與 Intel，最低 macOS 11；保留既有設定、詞頻、V1 舊版及其他輸入法。下載檔均附 SHA256 與建置資訊。

**目前未使用 Developer ID 簽署，也未經 Apple 公證。** 若 macOS 阻擋，確認來源與 SHA256 後，可到「系統設定 → 隱私權與安全性」使用「仍要打開」。不需停用 Gatekeeper 或 SIP。

### 驗證與邊界

- 記錄輪替、私有權限、並行寫入、半截記錄復原、符號／硬連結拒絕、隱私哨兵過濾、異常摘要、報告保留與錯誤節流均使用隔離資料驗證。
- 修復前留存、安全拒絕、冷卻／過期、一次重啟上限及 About／診斷視窗均有回歸檢查；沿用 Swift／Rust 95 場景／441 步輸入回歸。
- 系統端點事件可能無法識別所屬輸入法，會標示為未歸屬；不能單憑這些事件斷定倉頡星故障。程式致命崩潰由 macOS 留下報告，工具只擷取安全摘要。
- 不以日常輸入或詞頻作故障注入；長時間使用、實際故障復發與測試帳戶完整升級仍待驗收。Intel 為交叉編譯及切片檢查，本機實機為 Apple Silicon。
- BIG-5 字形過濾、舊版自訂符號分類與部分附加模組仍未完成。

既有 Shift 英文大小寫、解除安裝及安全升級功能保留；完整移除資料亦會移除診斷記錄。先前 Release 保留供回退。
