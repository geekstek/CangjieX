倉頡星 V2.0.2 修正「已安裝新版，但仍在執行舊版程序」的升級缺口。

### 推薦安裝方式

1. 下載 **CangjieX-2.0.2-universal.dmg**，開啟內部的 **倉頡星安裝器**。
2. 完成正在輸入的文字，切換到 **ABC**，並結束「系統設定」（Command＋Q）。
3. 按「安裝並啟用」，安裝期間保持 ABC。安裝器會保留設定及詞頻，停止舊程序、安裝新版、重新啟動並核對實際執行版本。
4. 只有執行版本、構建識別、PID／路徑及輸入源啟用通過核對，才顯示完成。無法安全重啟或確認啟用時，會明確要求保存工作後重新登入。

支援 Apple Silicon 與 Intel，最低 macOS 11。僅更新目前使用者的 V2 輸入法，保留既有設定、學習記錄、已安裝的 V1 舊版及其他輸入法。

**目前未使用 Developer ID 簽署，也未經 Apple 公證。** 若 macOS 阻擋，確認來源與 SHA256 後，可到「系統設定 → 隱私權與安全性」使用「仍要打開」。不需停用 Gatekeeper 或 SIP。

### 手動 .pkg

**CangjieX-2.0.2-universal.pkg** 保留作手動安裝；它明確宣告需要登出並重新登入，完成畫面亦標示「檔案已安裝，尚需重新登入啟用新版」。它不執行安裝腳本，也不會自動登出。

V2.0.0／V2.0.1 使用者如剛完成 .pkg 安裝但仍看到舊介面，請先完成組字並重新登入；原生 V2.0.2 安裝器會改為在流程中核對這個狀態。

### 本次修正

- 新增獨立原生安裝器，避免更新入口本身被舊版輸入法程序承接。
- 安裝前確認已切離倉頡星並結束系統設定，不直接中斷正在輸入的文字。
- 新版程序提供僅回報版本、構建識別及 PID 的本機查詢，不讀取或記錄使用者輸入。
- 使用編譯時寫入的構建識別核對執行程序；只讀取新版 Info.plist 不再被視為升級成功。
- 保留原有關於視窗的解除安裝功能，並新增 `CangjieXMaintenance activate` 安全重啟與核對指令。

### 驗證與邊界

- 既有 95 個場景／441 步輸入快照、設定與學習隔離、解除安裝與保護測試持續執行。
- 新增真實舊程序持續執行、磁碟執行檔已換新、相同版本不同構建、缺少回覆、PID／路徑不符及啟用失敗回歸；不能驗證時不得報完成。
- .dmg 已實際掛載，檢查內部原生安裝器的版本、簽章、雙架構、內附 .pkg 摘要與構建識別；手動 .pkg 已查詢確認為 RequireLogout。
- 測試使用隔離程序、檔案與服務名；未用日常安裝做完整更新或自刪測試，測試帳戶的完整系統升級驗收仍待完成。
- Intel 為交叉編譯及切片檢查，本機實機環境為 Apple Silicon。完整跨應用真實鍵盤驗收，以及 BIG-5 字形過濾、舊版自訂符號分類與部分附加模組仍未完成。

兩種下載檔均附 `.sha256`；`build-info.json` 記錄構建提交與簽署狀態。V2.0.0、V2.0.1 與 V1.x Release 保留供回退。
