倉頡星 V2.0.0 是 Swift 系統介面與 Rust 核心路線的首個可下載安裝版，顯示名稱統一為 **倉頡星**，內部沿用獨立識別，與舊版並存。

### 下載與安裝

1. 在下方 **Assets** 下載 **CangjieX-2.0.0-universal.pkg**。支援 Apple Silicon（arm64）與 Intel（x86_64），最低 macOS 11。
2. 完成目前的組字並切到 ABC，再開啟安裝包。只安裝到目前使用者的 `~/Library/Input Methods/CangjieXPreview.app`，不覆蓋舊版 app、偏好或詞頻；已有 Preview 則更新它。
3. 保存工作，在方便時登出並重新登入。
4. 到「系統設定 → 鍵盤 → 文字輸入 → 編輯 → ＋ → 繁體中文」加入 **倉頡星**，再從輸入選單啟用。先前已加入測試版時，重新登入後名稱會更新，不需重複加入。

**簽署狀態：** app 為 ad-hoc 簽署，安裝包未以 Developer ID 簽署，也未經 Apple 公證。若 macOS 阻擋，請確認是本倉庫下載的檔案後，在「系統設定 → 隱私權與安全性」使用「仍要打開」。不要關閉 Gatekeeper 或 SIP。

### 包含功能

- 倉頡、簡易、注音文校正及聯想詞。
- Swift 原生淺深色候選窗、滑鼠選字、翻頁與偏好設定。
- 繁體轉簡體、全形英數字與半角標點設定。
- 依選字次數調整候選順序，重啟後保留；倉頡與簡易分開保存設定及學習記錄。
- 舊版設定與學習紀錄只讀匯入，之後只儲存在 `~/Library/Application Support/CangjieX Preview/`。

### 驗證與範圍

- 原版 C++、Rust、Swift 重放 **95 個行為場景／441 步快照**；資料提取、Rust 所有權與原生組字測試通過。
- 候選學習已單獨驗證：選字重排、重新啟動保留、停用恢復碼表順序、重新啟用恢復歷史。
- 安裝包檢查 Universal 架構、app 版本及完整性，僅允許目前使用者目錄，不含安裝腳本，也不終止舊版程序。
- 完整跨應用真實鍵盤驗收尚未完成；BIG-5 字形過濾、舊版自訂符號分類與部分附加模組尚未遷移。
- 注音文校正只處理輸入法收到的文字，不掃描已上屏內容或攔截貼上。
- Intel 切片已交叉編譯與檢查；本地實機檢查環境為 Apple Silicon。

附帶 `.sha256` 可核對安裝包，`build-info.json` 記錄構建 commit、架構與簽署狀態。舊版 V1.x Release 保留供回退。
