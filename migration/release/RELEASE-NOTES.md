倉頡星 V2.0.5 改善日常輸入的候選範圍，並修正缺字顯示及診斷記錄。

### 日常用字

- 預設開啟「日常用字」，隱藏私用區字及本機一般軟體沒有可用字型的候選，避免候選窗可見、上屏後卻缺字的情況。
- 在 Rust 引擎分頁、編號及選字之前篩選，保留其餘候選的相對順序與重複項；不改寫原始碼表，也不刪除學習記錄。
- 倉頡、簡易各自保存開關。在「偏好設定 → 候選與提示」取消「日常用字」，即可恢復完整候選。
- 此功能是本機字形相容性篩選，不是嚴格的字頻清單或 BIG-5 篩選。原始輸入文字與取消校正時的原文不會被刪除。

### 候選字型備援

- 完整候選模式遇到系統缺字時，候選窗可使用隨附的 Jigmo2（CC0 1.0）及 CNS11643 正宋體 Plus（政府資料開放授權條款－第1版）。附有授權、著作權、固定來源及 SHA256，字型未經修改。
- 備援字型僅於候選窗缺字時載入，不安裝到使用者或系統字型目錄。仍無法對應的字以 `[U+碼位]` 標示，選取後保留原字碼。
- 候選窗字型不會套用到其他軟體；關閉日常用字後，罕用字上屏、分享或移到其他電腦時，仍需目標軟體有相應字型。

### 診斷記錄修正

- 維護命令失敗與實際修復失敗分開記錄，保存白名單命令類別及當時狀態；未知命令不保存原始參數。
- 當機摘要新增程式角色、可取得的版本／建置號與 PID，按報告實際時間排序。缺少有效時間時才使用檔案時間並標示來源，未知版本不填成目前安裝版本。
- 保留原有心跳、引擎錯誤、慢處理、系統端點摘要及安全修復。仍不記錄按鍵、字根、輸入文字、候選、詞頻、剪貼簿、視窗標題或完整系統／當機內容，亦不自動上傳。
- 修正診斷分類不代表已證明或解決所有「輸入法變灰」的根因；無法歸屬的系統端點訊號不能直接視為倉頡星故障。

### 安裝

推薦下載 **CangjieX-2.0.5-universal.dmg**，開啟內部的 **倉頡星安裝器**。先完成組字、切換 ABC 並結束「系統設定」，安裝期間保持 ABC。看到「已完成安裝並啟用新版」才算完成；若顯示尚未完成，請保存工作後重新登入。

手動 **CangjieX-2.0.5-universal.pkg** 安裝後須登出並重新登入。支援 Apple Silicon 與 Intel，最低 macOS 11。保留既有設定、詞頻、V1 舊版及其他輸入法；附件提供 SHA256 與建置資訊。

**目前使用 ad-hoc 簽章，未以 Developer ID 簽署，也未經 Apple 公證。** 若 macOS 阻擋，確認來源與 SHA256 後，可到「系統設定 → 隱私權與安全性」使用「仍要打開」。不需停用 Gatekeeper 或 SIP。

### 驗證與邊界

- Rust 核心含 32 項測試；保留原版 C++／Rust／Swift 的 95 場景、441 步行為比對，以及 82,873 筆倉頡碼表資料比對。既有 Shift 英文大小寫差異維持不變。
- 新增倉頡／簡易候選篩選、翻頁、數字選字、學習保留、開關隔離與重啟保存檢查；候選窗及偏好設定已檢查原生淺深色渲染。
- 備援字型檢查涵蓋漢字擴展區及碼表中的 10,790 個第 15 字面私用字；日常模式仍會排除私用字。
- 診斷使用隔離資料驗證分類、時間排序、舊記錄相容、隱私過濾、權限與保留上限；沿用安全修復、升級及解除安裝回歸。
- Universal 安裝包檢查 arm64／x86_64、版本、簽章、資源摘要及目前使用者安裝範圍。本機實機為 Apple Silicon；Intel 為交叉編譯及切片檢查。
- 完整跨應用真實鍵盤、長時間穩定性與測試帳戶完整升級仍待驗收；BIG-5 相容範圍、舊版自訂符號分類及部分附加模組尚未遷移。
