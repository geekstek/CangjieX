倉頡星 V2.0.3 新增依 Caps Lock 決定 Shift 英文大小寫的規則。

### 新功能

- **Caps Lock 關閉**：按住 Shift 輸入英文字母，輸出小寫，例如 Shift＋A → `a`。
- **Caps Lock 開啟**：按住 Shift 輸入英文字母，輸出大寫，例如 Shift＋A → `A`。
- 適用於倉頡、簡易，以及全形英文輸出（`ａ`／`Ａ`）。
- 候選窗開啟時，Shift＋字母也會切入英文，取代尚未確認的字根與候選。普通字根、Shift＋數字選聯想詞及系統快捷鍵維持原規則。
- 大小寫規則由 Rust 核心處理，Swift 沿用原生按鍵狀態及上屏流程。既有設定與詞頻保留。

### 下載與安裝

1. 推薦下載 **CangjieX-2.0.3-universal.dmg**，開啟內部的 **倉頡星安裝器**。
2. 完成目前組字，切換到 **ABC**，並結束「系統設定」（Command＋Q）。
3. 按「安裝並啟用」，安裝期間保持 ABC。安裝器會停止舊程序、安裝新版、重新啟動並核對實際執行版本；設定及詞頻保留。
4. 看到「已完成安裝並啟用新版」才算完成；若顯示尚未完成，請依提示保存工作後登出並重新登入。

支援 Apple Silicon 與 Intel，最低 macOS 11。僅更新目前使用者的 V2 輸入法，保留已安裝的 V1 舊版及其他輸入法。

手動 **CangjieX-2.0.3-universal.pkg** 安裝後須登出並重新登入；它不執行安裝腳本，也不會自動登出。兩種下載檔均附 `.sha256`，`build-info.json` 記錄來源提交及簽署狀態。

**目前未使用 Developer ID 簽署，也未經 Apple 公證。** 若 macOS 阻擋，確認來源與 SHA256 後，可到「系統設定 → 隱私權與安全性」使用「仍要打開」。不需停用 Gatekeeper 或 SIP。

### 驗證與邊界

- 29 項 Rust 測試，以及 Swift → Rust 的 95 個場景／441 步快照回歸；原始 C++ 參考快照保持不變，Shift 英文的刻意差異另外明確核對。
- 新增 26 個英文字母、兩種 Caps Lock 狀態、倉頡／簡易、半／全形、含 Shift／Caps Lock 的系統快捷鍵回歸。
- 原生 NSEvent → Rust → NSTextView 回歸涵蓋空白、已有字根、手動候選及即時候選，確認單次上屏、不重複輸入。
- 安裝包檢查版本、雙架構、簽章、目前使用者限定目錄及無安裝腳本；.dmg 實際掛載後核對內部安裝器與套件摘要，手動 .pkg 核對 RequireLogout。
- 測試使用隔離資料，不安裝或卸載日常輸入法。真實鍵盤連續試打及測試帳戶完整升級仍待驗收；Intel 為交叉編譯與切片檢查，本機實機為 Apple Silicon。
- BIG-5 字形過濾、舊版自訂符號分類與部分附加模組仍未完成。

既有關於視窗的解除安裝與安全升級啟用功能保留。先前 V2 與 V1.x Release 保留供回退。
