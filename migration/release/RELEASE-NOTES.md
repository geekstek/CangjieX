倉頡星 V2.0.1 新增「關於倉頡星」中的解除安裝按鈕，並改善升級後舊名稱、空白輸入來源與卸載殘留的處理。

### 下載與安裝

1. 在 **Assets** 下載 **CangjieX-2.0.1-universal.pkg**，支援 Apple Silicon 與 Intel，最低 macOS 11。
2. 完成組字並切換到 ABC，再開啟安裝包。
3. 保存工作後登出並重新登入，再從輸入選單選取「倉頡星」。可在「關於倉頡星」確認版本為 2.0.1。

安裝包僅安裝至目前使用者目錄，保留既有 V2 設定與學習記錄，也不覆寫 V1 舊版。內部 Preview 識別與資料目錄繼續沿用，避免破壞既有設定。

**目前未使用 Developer ID 簽署，也未經 Apple 公證。** 若 macOS 阻擋，確認來源與 SHA256 後，可到「系統設定 → 隱私權與安全性」使用「仍要打開」。不需停用 Gatekeeper 或 SIP。

### 本次更新

- 在右上角「倉頡星 → 關於倉頡星」新增 **解除安裝倉頡星…**。
- 刪除前顯示明確確認，可選擇一併刪除設定與學習記錄；Return、Escape 和取消均不會觸發刪除。
- 卸載使用複製至私有暫存目錄的獨立原生工具，app 移除後仍能完成清理、檢查與顯示結果。
- 停用 V2 輸入源，移除 app、安裝收據及所屬啟用／歷史記錄，按選擇移除 V2 設定、詞頻與快取；保留已安裝的 V1 舊版與其他輸入法。
- 重建鍵盤設定獨立的輸入法目錄快取、刷新右上角選單，改善舊 Preview 名稱與空白項目。
- 若系統仍保留登入階段的目錄，會提示登出並重新登入；不保證所有 macOS 版本都能在不登出的情況下立即刷新全部畫面。
- 開發更新改為完整替換 app bundle，避免舊語系名稱資源殘留。

### 解除安裝

先結束「系統設定」（Command＋Q），再從「關於倉頡星」開啟解除安裝。預設勾選一併刪除設定與學習記錄；如需保留，取消勾選。明確點擊「解除安裝」後，工具會切換至 ABC 再執行。

終端機的 `CangjieXMaintenance uninstall` 預設保留設定，加入 `--delete-data` 才完整移除資料。`repair` 可修復註冊與快取，`status` 僅查詢。

### 驗證與目前範圍

- 原有 Swift／Rust 輸入行為仍以 **95 個場景／441 步快照** 比對，倉頡及簡易學習保存、設定隔離與原生候選操作均有測試。
- 新增隔離升級、完整／保留資料卸載、符號連結保護、收據與快取清理、獨立工具簽章與自刪後執行測試。
- 關於及確認介面已以獨立測試程式觀察，取消、Return、Escape 與防重複啟動已驗證；未用日常安裝做破壞性卸載測試，測試帳戶的完整系統清單自刪驗收仍待完成。
- 安裝包展開後檢查版本、兩個原生執行檔的 arm64／x86_64 切片、簽章、檔案完整性及目前使用者安裝範圍；不含安裝腳本。
- Intel 為交叉編譯與切片檢查，本機實機環境為 Apple Silicon。完整跨應用真實鍵盤驗收，以及 BIG-5 字形過濾、舊版自訂符號分類與部分附加模組仍未完成。

附帶 `.sha256` 與 `build-info.json`，可核對下載摘要、構建提交及簽署狀態。V2.0.0 和 V1.x Release 保留供回退。
