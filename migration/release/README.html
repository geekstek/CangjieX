倉頡星 CangjieX 2.0.5（手動安裝包）

此 .pkg 安裝後需要登出並重新登入。 推薦使用同版本 .dmg 內的「倉頡星安裝器」，在安全切離輸入法後完成重啟與執行版本核對。

Swift 系統介面與 Rust 輸入核心。支援 Apple Silicon 與 Intel，macOS 11 或更新版本。

包含倉頡、簡易、注音文校正、聯想詞、繁簡轉換、全形英數字、候選排序學習及獨立偏好設定。

預設開啟「日常用字」，隱藏私用字與本機缺字候選；可在「偏好設定 → 候選與提示」關閉，倉頡與簡易各自保存。保留原始碼表、候選相對順序及學習記錄，亦不安裝使用者字型。完整候選模式在候選窗使用隨附備援字型；上屏後仍依目標軟體的字型顯示。

提供本機診斷記錄及「關於倉頡星 → 診斷與修復…」。維護命令失敗與修復失敗分開記錄，當機摘要包含可取得的角色、版本、PID 與實際時間。記錄不含輸入內容、候選或詞頻；修復前先保存診斷，保留設定及學習記錄。輸入法變灰時，也可直接執行 app 內的 CangjieXMaintenance diagnostics-dialog 開啟獨立工具。

安裝前

請先完成目前的組字，切到 ABC，再繼續安裝。安裝後請在方便時登出並重新登入。

本版顯示名稱為「倉頡星」，內部沿用獨立識別，僅安裝至目前使用者的 Library/Input Methods/CangjieXPreview.app。保留舊版倉頡星，亦不覆寫其設定或使用者詞頻。已有測試版時會更新該版本。

版本範圍

這是 Swift / Rust 路線的 V2.0.5，顯示名稱統一為「倉頡星」。完整跨應用人工驗收尚未完成；BIG-5 字形過濾、舊版自訂符號分類及部分附加模組尚未遷移。

注音文校正僅處理輸入法收到的文字，不會掃描文件或攔截剪貼簿貼上。

簽署狀態

此安裝包未以 Developer ID 簽署，亦未經 Apple 公證。請僅從 geekstek/CangjieX 的 GitHub Release 下載，並核對 SHA256。若 macOS 阻擋，請在「系統設定 → 隱私權與安全性」確認來源後使用「仍要打開」；不需要關閉 Gatekeeper 或 SIP。
