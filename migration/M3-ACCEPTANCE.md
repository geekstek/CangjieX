## 实际试打前

1. 默认只使用 **CangjieX Preview** 和一次性测试文档。旧版对照先使用已录制的原版基线，不要求你在日常旧版中反复选字；那样可能触发旧版本身的词频学习。
2. 不重置、删除或覆盖旧版词频来强行统一排序。Preview 首次只读导入后会独立学习，两边当前次序可能已经不同。记录屏幕上实际显示的顺序，不把“第二项”固定理解为“曰”。
3. 打开 `build/migration/preview/CangjieX Preview Test.app`，按「使用 Preview」，确认状态栏显示 `io.github.geekstek.inputmethod.CangjieXPreview`。试打工具使用 macOS 文本与输入源 API，不直接调用 Rust。
4. 若尚未启用，在系统设置的「键盘 → 文字输入 → 编辑 → 加入 → 繁体中文」中加入 CangjieX Preview，保留原有 ABC 和「倉頡星」。若切换失败，记录实际输入源 ID，先不要改查表或词频设置。
5. 初始检查关闭 Caps Lock，使用 ABC 键盘布局。必须实际按键；粘贴 `oiar` 不能代替输入四个字根。
6. 每条测试前，先按 Escape 结束上一次组字／关联词提示，再在测试框用 Command+A、Delete 清空。不要清空自己的工作文档。结束后按「还原输入源」或关闭试打工具。
